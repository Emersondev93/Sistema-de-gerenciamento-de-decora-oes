# Sistema de gerenciamento de decorações

Projeto desenvolvido com Java para gerenciamento de decorações de festas.

## Objetivo

Criar um sistema para auxiliar empresas de decoração de eventos no gerenciamento de:

- Clientes
- Eventos
- Itens de decoração
- Agenda
- Pagamentos

O projeto será desenvolvido de forma incremental conforme o avanço dos meus estudos em Java, Programação Orientada a Objetos, Banco de Dados e Spring Boot.

## Tecnologias

- Java
- Git
- GitHub
